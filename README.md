## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/iotb-tech/group-3-primaltraining.git
cd group-3-primaltraining
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
